# Glade Bank — Frontend Mockup

Clickable UI mockup (demo data only, no Supabase calls yet).

## Run locally
```
cd frontend
npm install
npm run dev
```

## What's inside (`frontend/src`)
- `App.jsx` — customer screens + admin console
- `Extra.jsx` — extra pages (sign in, reset, verify, local transfer, bills, cards, statements, security, limits, support, admin tools); open via **More**
- `styles.css` — styling

All balances, rates and transactions are simulated.
